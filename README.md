# Sudoku Simulator — Android Studio source project

Included:
- Kotlin + Jetpack Compose Android application
- Offline play; no login or network permission
- 9 levels across Factory, Hospital, and Market
- Standard 9×9 Sudoku interface
- 3 starting hearts, mistake penalties, bonus hearts, Game Over, Retry, and Quit to level selection
- Math word-problem challenges
- Local level-unlock progress saved on the device

## Run it
1. Install Android Studio and the Android SDK (API 35).
2. Extract this ZIP.
3. In Android Studio select **Open** and choose the `SudokuSimulatorAndroid` folder.
4. Wait for Gradle sync.
5. Run on an emulator or an Android phone with USB debugging enabled.

## Important
This ZIP contains Android source code, not a precompiled APK. It must be built and tested in Android Studio before installation or distribution. This prototype uses valid Sudoku solution patterns, but random clue removal does not yet guarantee a unique solution for every puzzle.
